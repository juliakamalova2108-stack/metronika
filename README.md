# Метроника — HTML-прототип

Кликабельный прототип мобильного приложения для мастеров по поклейке обоев, диспетчеров и агентов (продавцов, дизайнеров). Открывается в браузере любого телефона, ставить ничего не нужно.

Дизайн и компоненты взяты из секции «Выезды» в Figma (`METRONICA MASTER — рабочий проект`), функционал — из секций «Вход», «Заказы», «Канбан», «Настройки», «Статистика», «Профиль».

## Как запустить

Нужен любой статический веб-сервер (модули JavaScript не грузятся с `file://`):

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000`. Для GitHub Pages: Settings → Pages → ветка `main`, папка `/`.

## Что работает (этапы 1–2)

- Вход: телефон → код → PIN, регистрация с выбором роли и согласиями, повторный вход по PIN, «Не помню PIN».
- Агент: сканер штрихкода (ввод цифр вместо камеры), добавление обоев, которых нет в базе; расчёт «по рулонам» и «по размерам» с окнами и дверями; выбор партнёра по его прайсу, свободной даты и времени; процент (по умолчанию 5%); данные клиента; проверка дублей; «Мои заявки», повторная передача.
- Мастер и диспетчер: входящие предложения, принятие с фиксацией процента, отклонение без неустойки, отказ с неустойкой по правилу (500 ₽ / 30% не менее 1 000 ₽ / 50% не менее 1 500 ₽); карточка заказа с вкладками Канал, Клиент, Оценка, График, История.
- Начисления: кто кому сколько должен, отметка выплаты и подтверждение получения.
- Скрытие агента от мастера в цепочке через диспетчера («Контролёр»).

## Устройство

- `js/calc.js` — расчёты (рулоны, площадь, стоимость, комиссия, неустойки), чистые функции.
- `js/store.js` — данные и действия: заказы, звенья передачи, начисления, журнал.
- `js/seed.js` — тестовые данные и рекомендованный прайс системы.
- `js/auth.js`, `js/agent.js`, `js/pro.js`, `js/shared.js` — экраны.
- `js/app.js` — оболочка, меню, навигация.
- `css/app.css` — стиль «зелёное стекло» из Figma.
