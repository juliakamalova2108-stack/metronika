# Метроника — HTML-прототип

Кликабельный прототип мобильного приложения для мастеров по поклейке обоев, диспетчеров и агентов (продавцов, дизайнеров). Открывается в браузере любого телефона, ставить ничего не нужно.

Дизайн и компоненты взяты из секции «Выезды» в Figma (`METRONICA MASTER — рабочий проект`), функционал — из секций «Вход», «Заказы», «Канбан», «Настройки», «Статистика», «Профиль».

## Как запустить

Нужен любой статический веб-сервер (модули JavaScript не грузятся с `file://`):

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000`. Для GitHub Pages: Settings → Pages → ветка `main`, папка `/`.

## Что работает

**Вход.** Телефон → код → PIN, регистрация с ролью и согласиями, вход по PIN, «Не помню PIN».

**Агент.** Сканер штрихкода (цифры вместо камеры), добавление обоев не из базы, расчёт «по рулонам» и «по размерам» с проёмами, выбор партнёра по его прайсу и свободной дате, процент (5% по умолчанию), клиент, проверка дублей. «Мои заявки» и карточка заказа целиком (только чтение и чат), повторная передача после отказа. «Звонки клиентам» через 3 дня после закрытия, «Для клиента» — предложение, памятка, визитка с промокодом (копирование текста). Настройки: тариф, партнёры, промокод.

**Мастер и диспетчер.** Канбан «Входящие / Замер / Согласование / Очередь / В работе / Выполнено / Архив» с поиском, корзина. Свой заказ в 3 шага: комнаты по этажам → услуги и объёмы с калькулятором → канал, клиент, дата → «На замер», «На согласование» или «В очередь». «Текущий заказ» — ближайший выезд.

**Карточка заказа (секция «Выезды»).** Канал и договорённости, Клиент, Оценка по комнатам и услугам со сроком в сменах, График (замер, даты комнат, геоотметки), Материал по комнатам со сканированием и отзывами мастеров, Смета по стенам (рулетка — имитация прибора, окна и двери, услуги на стену, версии сметы, смета для клиента), Чат участников, Задачи, Финансы (доходы, расходы, итог). Этапы: Замер → Согласование → Очередь → В работе → Выполнено → Закрыт.

**Диспетчер.** Команда (приглашение по телефону, места в подписке), передача мастеру всего заказа или отдельных комнат со своим процентом, «ищем замену» после отказа мастера, «Замену не нашёл» и автозакрытие в момент приезда с неустойкой агенту, 700 ₽ если агент сам нашёл замену. Мастер у диспетчера видит агента как «Контролёр».

**Деньги и рейтинг.** Начисления по каждому звену: ориентировочно → к выплате → выплачено → получено. Итоговая комиссия = процент от работ из предварительной оценки по факту, но не меньше оценки; работы сверх оценки — без процента. Неустойки 500 ₽ / 30% не менее 1 000 ₽ / 50% не менее 1 500 ₽. Рейтинг — только подтверждённые м² поклейки (заказ заполнен, геоотметки, замер с рулетки, смета отправлена, заказ закрыт). Статистика за месяц, прошлый месяц и год. Бренд-зона: производители, каталог, советы, новости, опыт мастеров. Настройки: прайс по типам обоев, услуги с ценой и нормой, список комнат, рабочие дни и занятые даты, уведомления, PIN.

## Что имитируется

Камера, лазерная рулетка, геолокация (если браузер не дал координаты), SMS, оплата подписки, интеграции с Авито и мессенджерами. Данные живут в одном браузере, поэтому роли переключаются через «Меню → Сменить пользователя».

## Устройство

- `js/calc.js` — расчёты (рулоны, площадь, стоимость, комиссия, неустойки), чистые функции.
- `js/store.js` — данные и действия: заказы, звенья передачи, начисления, журнал.
- `js/seed.js` — тестовые данные и рекомендованный прайс системы.
- `js/auth.js` — вход; `js/agent.js` — новая заявка агента; `js/pro.js` — канбан, свой заказ, корзина; `js/order.js` — карточка заказа; `js/more.js` — профиль, настройки, команда, статистика, бренд-зона, звонки; `js/shared.js` — общие блоки и начисления.
- `js/app.js` — оболочка, меню, навигация.
- `css/app.css` — стиль «зелёное стекло» из Figma.
